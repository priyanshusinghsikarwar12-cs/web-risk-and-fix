# WebShield

WebShield is a beginner-friendly cybersecurity web app that helps website owners understand the security health of their website.

## Mission

Make website security simple, clear, and actionable for normal people.

## MVP Goal

A user enters their domain and receives a simple security report covering:

- HTTPS status
- SSL certificate health
- Security headers
- DNS records
- Basic risk score
- Plain-English fix suggestions

## Important Rule

WebShield will only perform deeper security scans on websites the user owns or has permission to test.
